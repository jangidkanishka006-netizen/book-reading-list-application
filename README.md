# Book Reading List Application

## About the Project
The Book Reading List Application is a Python command-line program that helps users organize their books and track their reading progress.

## Features
- Add books with their titles and authors.
- View all books in the reading list.
- Mark books as read.
- Track reading status: Read or To Read.
- Handle invalid menu choices and book numbers.

## Technologies Used
- Python 3

## Concepts Used
- Lists and dictionaries
- Functions
- Loops and conditional statements
- User input and output
- Exception handling

## How to Run
Make sure Python 3 is installed, then run:

```bash
python book_list.py
```

## Important Note
Books are stored in memory while the program runs. The list resets when the application exits.
